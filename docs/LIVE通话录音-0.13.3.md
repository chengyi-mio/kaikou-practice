# LIVE 通话录音 · 0.13.3

更新日期：2026-11-07。当前分支包含源码更新，GitHub 安装包尚未发布到此版本。

## 使用流程

1. 进入“模拟面试 → LIVE 实时面试”，准备简历、岗位 JD 及实时模型配置。
2. 核对免费额度和目标模型的“免费额度用完即停”状态；当前试用支持北京地域，单轮 5 或 10 分钟。开始前阅读数据发送及录音说明。
3. 接通后自动录制本人和 AI 面试官声音，界面显示“正在录制双方声音”。建议戴耳机，避免扬声器回声。
4. 点击“结束 / 暂停通话”，等待录音区显示“已保存到本机”。断线后也会保留已录制的内容，重连另存一段。
5. 在通话控制下方点击“回放录音”或“下载录音”。回放支持拖动进度，下载格式为 WebM/Opus。开始新一轮后，可从“以前的通话录音”查看。
6. 如需 AI 复盘，单独点击复盘按钮。录音保存不依赖复盘；同一轮已经生成复盘时，录音旁提供对应入口。

## 保存与恢复边界

- Web Audio 混合麦克风与远端音轨，MediaRecorder 编码录音；通过独立 IndexedDB 数据库 `kaikou-live-recordings` 分段保存并关联面试轮次 ID。
- 沿用 `userData=KaikouPractice` 与 `partition=persist:kaikou`。原练习、面试文字、复盘和加密密钥不迁移、不清理。
- 结束通话后等待最后录音片段写入，再标记已保存，并补充 WebM 时长元数据供播放与定位使用。
- 静音与打断会同步影响对应的录音输入；录音不能恢复当时已静音或未收到的声音。
- 保存失败时明确显示未完整保存，保留内存临时副本，可立即下载或重试。此时不要关闭页面。
- 异常退出后可恢复已成功写入的连续片段，标注“中断保留”。未收到或未写入的尾部声音不能保证恢复。
- 删除前确认，只删除所选本机音频；文字、AI 复盘和已下载的副本仍保留。
- 0.13.2 及更早版本未录制的 LIVE 通话不会因升级产生录音；已保存的文字和复盘继续可用。

## 验证结果

2026-11-07 使用本版本完成：

- 单元测试 86 项通过；AI 入口恢复测试 9 项通过；LIVE 录音测试 5 项通过。
- 原生 WebRTC/MediaRecorder 测试使用两种独立频率，解码保存文件后确认麦克风与远端声音都存在；另测静音和打断后对应音轨能量下降。
- 验证结束后保存、回放、进度定位、下载、页面重载后保留、断线续接分段、异常退出片段恢复，以及存储失败后的临时下载与重试。
- 从 0.13.2 升级到 0.13.3 的桌面测试使用隔离数据、虚构密钥和独立端口，确认练习历史、旧录音字节、加密配置和新旧练习 AI 点评入口保留。
- 另一次独立真实千问联调使用虚构简历和本机合成候选人声音：通话计时 78 秒、模型回报 3,410 tokens，应用自动保存 77.1467 秒、757,012 字节的录音。重启测试程序后仍可回放、定位及下载。
- 对从应用实际下载的文件进行离线转写，确认同时包含面试官提问、候选人回答和追问。该次验证未使用真人麦克风，不代表所有硬件、噪声及网络条件均已覆盖。

用量是模型响应中的 token 计数，不是账单结算结果。免费额度及实际扣费以各自服务商账户为准。
