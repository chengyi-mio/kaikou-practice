# LIVE 免费额度试用（0.13.1）

本轮要求：阿里云免费额度，单轮 10 分钟，先不启用付费。更新日期：2026-11-07。

## 设计与边界

- 沿用 0.13.0 的 WebRTC 双向语音、简历与 JD、实时字幕、语音打断、断线恢复及独立 AI 复盘。
- 北京地域，免费检查记录未完成、过期或超过 12 小时，服务端拒绝握手，前端保留入口并提示处理方式。单轮限 5 或 10 分钟，旧的 15 分钟草稿保留但需开始新一轮试用。
- 额度检查来自人工核对的控制台状态，不是 API Key 自动查询结果。记录额度余量、到期日、核对时间。切换空间、地域、模型或密钥会使先前检查失效；留空保存继续复用密钥，但不延长检查有效期。
- 免费保障依赖阿里云服务端目标模型的“免费额度用完即停”，不是本机计时器或勾选框。调用前需确认该开关已生效。不调用购买、充值或付费开通接口，也不自动替换模型。
- 逐响应保存 `response.done.usage`，按输入/输出、音频/文字显示 tokens。重复响应不会重复累计；旧记录和缺失分项显示“未完整回报”，不伪造零消耗。用量 JSON 不包含密钥、简历或回答。
- 使用额度与支付金额分开。未完成响应可能尚未回报，账单及最终额度扣减必须回到控制台核对。面试复盘保留单独按钮，不自动调用 Agnes。
- 真实联调发现：仅设置 `session.instructions` 后发送空 `response.create` 会被服务拒绝。首轮 `response.create.response.instructions` 显式带入面试上下文和开场要求，避免空对话连接立即失败。
- 配置确认前使用 `replaceTrack(null)` 暂时拆下麦克风音轨，收到 `session.updated` 后接回，避免静音包先进入云端造成断句配置失败。
- 真实语音联调发现自动回复会把句间停顿当作回答结束。现在使用 `server_vad` 转写、`create_response:false`，在服务端停止说话事件后继续等待用户选择的思考时间，再明确请求一次追问；继续说话、打断和结束都会取消尚未发出的追问。总等待包含云端断句时间和本地思考时间。
- 中断或失败的面试官回答标为“已打断”，不作为完整题目参与复盘；短小残句不切断同一道题的连续回答。
- 原 AI 点评入口、旧历史、口才草稿、原服务密钥及 `persist:kaikou` 均保留。

## 官方依据

- [免费额度与用完即停规则](https://help.aliyun.com/zh/model-studio/new-free-quota)：北京地域、模型额度独立、用完即停和开关生效延迟。
- [Qwen-Omni-Realtime 接入](https://help.aliyun.com/zh/model-studio/realtime)：业务空间域名、WebRTC 信令及上下文累计计量。
- [服务端事件](https://help.aliyun.com/zh/model-studio/server-events)：响应用量及模态分项。

## 验证范围

- 单元测试覆盖：免费检查缺失/过期/地域错误/超时长不发起云端调用；用完即停错误无付费回退；密钥变更使检查失效；未知用量与零值区分。
- 界面测试覆盖：入口稳定、旧草稿隔离、旧 LIVE 复盘兼容、字幕/断线/重连/自动结束、AI 失败恢复、用量导出。
- 桌面升级仅使用虚构密钥、隔离数据及独立端口；真实免费模型联调是另一套独立数据，使用新建 LIVE 密钥与虚构简历、岗位、Windows 本机合成语音，不使用真实练习和录音。
- 真实联调记录与截图位于 `outputs/live-aliyun-20261107`。真实联调完成与否、实际用量以该目录中的结果报告为准，测试替身通过不等于真实模型成功。
