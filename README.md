# 开口练习

一个用于表达训练、思维框架学习与模拟面试的 Windows 桌面应用。选择场景和表达框架，录音或输入文字，再根据 AI 点评进行下一轮练习；也可上传简历和岗位 JD，与 AI 面试官进行 LIVE 语音对练。

**当前源码版本：0.13.3。** 新版包含 LIVE 双方通话录音、自动保存、回放和下载。本次同步源码，尚未发布对应的 GitHub 安装包；已发布安装包仍为 0.10.3，不包含后续新增功能。

## 下载使用

**[下载已发布的 Windows 安装包 v0.10.3](https://github.com/chengyi-mio/kaikou-practice/releases/download/v0.10.3/Kaikou-Setup-0.10.3.exe)** · [已发布版本](https://github.com/chengyi-mio/kaikou-practice/releases)

体验 0.13.3 请按下方源码运行方式启动，或在本机执行 `npm run desktop:pack` 构建安装包。

适用于 Windows x64。安装后从桌面快捷方式启动，无需安装 Node.js。当前安装包未进行代码签名。

1. 打开「设置与服务状态 → AI 服务配置」。
2. 选择 Agnes AI、DeepSeek、TypeSafe / Jev 或兼容服务，填写自己的 API Key，确认服务地址和模型名。
3. 点击「测试连接」，再点击「保存并生效」。模型权限、额度和费用以服务商账户为准。
4. 选择题目，输入文字或录音。转写文字准备好后可直接生成 AI 点评，不必先修改；发现识别错误时可以修正。

未配置模型时只有明确标注的基础反馈。**安装包支持录音，但不包含本地转写所需的 Python 和语音模型。** 需要转写时请准备下方环境，或配置云端转写；也可直接输入文字练习。

## 功能

- 真实任务入口：围绕工作汇报、解释延期、提出需求和面试回答，填写听众、目标、背景与可修改的检查重点，再进行录音或文字练习。
- 即兴表达、逻辑表达、复述表达三种训练方式。
- 按汇报、面试、说服、复盘等场景推荐表达结构。
- 表达结构、场景框架及示例，帮助理解每一步应该说什么。
- 录音、计时、音量显示、回放、下载和转写文字修改。
- Agnes 多维点评：切题与重点、结构与逻辑、事实具体程度、听众与沟通目的、文字清晰简洁、结论与下一步。结合场景给出原话依据、分析、改进建议和优先练习任务。
- Jev 场景规则判断，展示检查结果与置信度。
- 21 天训练计划、历史练习、保存点评与导出文字。
- AI 点评后可连续生成听众追问、朗读问题、录音作答；前几轮问答会随练习保存并用于下一轮追问。Jev 当前只支持规则点评，追问需 Agnes 或兼容聊天模型。
- 点评引用能在有可信转写时间戳时跳转到录音原话；没有时间戳或引文重复时不提供伪精确定位。
- 历史页可按能力和时间范围查看同模型、同版本、同场景及同标准下的逐次判断和原话依据；录音观察在有可信转写时间戳时显示识别片段字速与较长间隔，否则只提供低音量提示。它们均不是声音评分。
- 模拟面试：导入简历和岗位 JD，生成针对性问题，逐轮录音或文字作答，并生成带原话依据的 AI 面试复盘。
- LIVE 实时面试：千问 WebRTC 双向语音、实时转写、追问、打断、静音、断线续接与实际用量记录；使用独立的实时模型配置。
- LIVE 双方录音：接通后自动录制，结束或断线后保存到本机，支持回放、定位、下载和删除；文字与复盘单独保留。

点评基于转写文字，不评价发音、语调或情绪。开放式表达没有唯一标准答案，参考框架中的事实需要自己补充。AI 判断可能有误，请结合实际沟通目的使用。

## v0.13.3：LIVE 通话录音

- 每次接通自动混合录制本人和面试官的声音；结束或断线后自动保存，不依赖生成 AI 复盘。
- 通话控制下方直接展示本轮录音，提供回放、进度定位、下载、删除和关联复盘入口。重连另存一段，开始新一轮仍可查看以前的通话录音。
- 保存失败时保留临时副本，提供下载和重试；异常退出后可恢复已写入的连续片段，但不能保证未写入的尾部音频完整。
- 删除录音仅删除选定的本机音频，保留文字、AI 复盘及已经下载的副本。旧版本未录制的声音无法补回。
- 固定本机数据目录和存储分区，保留原练习、面试记录和密钥，新练习及历史练习的 AI 点评入口继续可见。

[使用与验证说明](docs/LIVE通话录音-0.13.3.md)。

- 新增简历/JD 导入、专属面试问题、逐轮回答与四维复盘，以及独立的 LIVE 实时语音模式。
- LIVE 通话界面显示双方席位、当前问题、连接状态和累计时长；可调整思考停顿、打断面试官、静音或结束通话。

- 实时语音密钥与普通 AI 点评密钥分开加密保存，重启后复用。生成复盘是单独的 AI 请求，不会在结束通话时自动调用。

## 本地语音转文字（可选）

准备可通过 `python` 命令运行的 Python 环境，然后执行：

```powershell
python -m pip install faster-whisper
python -c "from faster_whisper import WhisperModel; WhisperModel('small', device='cpu', compute_type='int8')"
```

第二条命令首次需要联网下载模型。使用相同 Windows 用户完成下载后重启应用。应用在 CPU 上离线加载已缓存的 small 模型，录音时不会自动下载模型。启动检查未通过时会提示本机转写不可用。

也可在 `%APPDATA%/KaikouPractice/services.env` 配置 `ASR_BASE_URL`、`ASR_API_KEY` 和 `ASR_MODEL`，保存后重启应用，使用兼容的云端转写。点评服务和语音转写服务分别配置。

## 源码运行

需要 Node.js 22.12+ 和 npm。

```powershell
git clone --branch feat/live-interview-recording-0.13.3 https://github.com/chengyi-mio/kaikou-practice.git
cd kaikou-practice
npm ci
npm run build
npm start
```

浏览器访问 http://127.0.0.1:4173 。网页版本需将 `.env.example` 复制为 `.env`，填写自己的服务参数并重启服务。不要上传 `.env` 或密钥。

```powershell
npm run dev           # 网页开发
npm run desktop       # 桌面启动，先执行 npm run build
npm run desktop:pack  # 生成 Windows 安装包
npm test              # 服务与规则测试
npm run test:e2e      # 浏览器流程测试，需要 Microsoft Edge
npm run desktop:test # 桌面流程测试
```

当前服务仅监听本机。手机使用需要可访问的 HTTPS 环境；公开多人服务需要鉴权、额度管理等配套功能。

## 数据与密钥

练习文字、点评和音频保存在本机，不自动跨设备同步。桌面版与浏览器版使用独立存储。删除应用数据前请先导出重要记录。

桌面版 AI 密钥经 Windows 加密后存于 `%APPDATA%/KaikouPractice/ai-service.json`，不会回传到界面。生成 AI 点评会将本次文字、题目和相关参考材料发送给所配置的模型服务；云端转写会发送本次录音。本地转写不上传录音，浏览器语音识别可能依赖浏览器厂商在线服务。

LIVE 实时服务密钥独立保存在同目录的 `live-service.json`。开始 LIVE 会将本轮简历、JD、相关对话及麦克风音频发送给所配置的实时服务商。双方通话录音另存于本机录音库，不为保存录音额外上传；点击“下载录音”可导出独立 WebM 文件。自动保存不等于跨设备备份，清理应用数据前应下载重要音频。

仓库和安装包不含作者的 API 密钥、个人练习记录或操作录屏。

## 项目结构

- `src/`：训练页面、表达结构、录音、历史和设置。
- `server/`：AI 点评、场景规则、转写接口与数据校验。
- `desktop/`：Windows 窗口、配置存储、本地转写与打包。
- `tests/`：服务和交互测试。
